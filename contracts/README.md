# StacksClubVault

The onchain half of 3AM's baskets. A basket is called a "Stack" in the contract and the database.

- Deployed on BNB Smart Chain mainnet:
  [`0x2a03793A4E00cD639F1811Fc2c0d3f14c78Aec17`](https://bscscan.com/address/0x2a03793A4E00cD639F1811Fc2c0d3f14c78Aec17) (verified)
- Solidity 0.8.28, OpenZeppelin v5, Foundry
- Full spec: [`../docs/CONTRACTS.md`](../docs/CONTRACTS.md)

## What it does

| Function | Who | What |
| --- | --- | --- |
| `createStack(assets, weightsBps, metadataURI, ticker)` | anyone | Stores an immutable recipe: 2 to 5 allowlisted tokens, weights summing to 10,000 bps, unique ticker |
| `payBuyFee(stackId, gross)` | buyer | Takes the 1% buy fee in USDT and issues a single-use receipt. Basket buys credit 25% of the fee to the creator. |
| `openPosition(stackId, receiptId, amounts)` | buyer | Pulls the exact tokens bought and mints a non-transferable position NFT that records the raw units. Rejects fee-on-transfer tokens. |
| `release(positionId, bps, purpose)` | position owner | Releases a fraction of every component back to the owner (used by Sell and Redeem). Never blocked by pause. |
| `paySellFee(positionId, proceeds)` | seller | 1% fee on the actual sale proceeds |
| `claimCreatorFees()` | creator | Withdraws the creator's accrued share |
| `withdrawPlatformFees(amount)` | admin | Capped at accrued platform fees |
| `addAsset`, `setAssetAllowed` | asset admin | Allowlist management (only affects new activity) |
| `pause`, `unpause` | pauser | Blocks new stacks, fees and positions. Releases and claims still work. |

**No role can move tokens that belong to positions, or creators' claimable fees.**

## Layout

```
src/StacksClubVault.sol        the contract
test/StacksClubVault.t.sol     unit tests
test/VaultInvariants.t.sol     invariant tests (accounting always matches balances)
test/VaultFork.t.sol           BSC mainnet fork test with the real bStocks and Ondo tokens
test/fork-assets.json          the tokens the fork test runs against (generated by the seed script)
script/Deploy.s.sol            deploy script (reads the deployer key from the environment only)
deploy/assets.json             the allowlist added at deploy time
broadcast/…/56/                the mainnet deployment record
```

## Build and test

```bash
forge install --no-git foundry-rs/forge-std OpenZeppelin/openzeppelin-contracts@v5.4.0
forge build
forge test                                               # unit + invariant; fork tests skip without an RPC
BSC_RPC_URL=<bsc mainnet rpc> forge test --match-contract Fork -vv
```

Current result: 45 passing tests (unit and invariant), plus 2 fork tests that run when
`BSC_RPC_URL` is set. On 2026-09-27 the fork test sent all 86 tested tokens (46 bStocks, 40 Ondo)
through the vault and back, unit for unit.
